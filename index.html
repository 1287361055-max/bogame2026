🛠️ 关于本项目 About

轻量、离线、开箱即玩

整个项目由原生 HTML / CSS / JavaScript 编写，不依赖任何框架或构建工具。 直接双击 index.html 即可游玩，也可以用任意静态服务器托管（含 GitHub Pages）。

  • 零依赖：不需要 npm install，不需要联网加载资源。
  • 统一体验：共享顶栏、计分、音效与本地高分存档。
  • 键盘 + 触屏：桌面用方向键 / WASD / 鼠标，移动端支持触摸与滑动。
  • 响应式：画布自适应缩放，窄屏自动切换为单列布局。
